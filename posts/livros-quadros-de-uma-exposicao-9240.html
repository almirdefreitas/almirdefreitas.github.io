Livros, quadros de uma exposição

21 set 2011

Esse cara, Mike Stilkey, montou essas instalações com livros, usados tanto como tela para a pintura ou/e como peças de uma escultura. Tem um tempinho que ele vem fazendo, mas sempre vale para quem ainda não viu. Como tá sempre valendo lembrar aqui: clique em "I" para ler a legenda e em "FS" para ver em tela cheia.
